Portafolio de Mateo Cardenas
este es mi portafolio personal, Lo estoy construyendo mientras aprendo desarrollo web y lo voy ajustando

la idea es tener un espacio para presentarme, mostrar mis habilidades, compartir proyectos y recibir mensajes
que incluye
- Un menu con enlaces a las secciones de la pagina.
- mi presentación y una foto de perfil circular.
- una sección sobre mi.
- mis habilidades en HTML, CSS, javaScript basico y python.
- Tres tarjetas de proyectos.
- un formulario de contacto conectado a formsubmit.
- unlaces a mi correo y mi perfil de github.
el diseño se adapta a celulares y computadores. El fondo tiene un degradado morado y azul, y los campos del formulario tienen un color distinto al panel que los contiene.

formulario de contacto
el formulario solicita nombre, correo y mensaje. Los tres campos son obligatorios y se envían mediante POST a FormSubmit, con mi correo configurado como destinatario.

Para completar la configuración inicial, debo enviar una prueba y confirmar el correo de activación que manda FormSubmit. Despues puedo hacer otro envío para comprobar la recepcion, la confirmación de activacion y la recepción del mensaje están pendientes de verificar.
